# 相亲匹配判断规则库 v1.0

> 来源：抖音「苏锡常大王说媒」（账号A）与「苏州金大王」（账号B）共 200 条视频口播转写稿的结构化蒸馏。
> 说明：两个账号签名、微信号、办公地址完全一致，实为同一机构的两个分发账号，因此本规则库反映的是**一套话语体系**，而非两家独立机构。
> 用途：① 还原博主用于判定「你追不追得到」的底层规则；② 作为「合拍率」H5 的评分引擎规则来源。

---

## 一、底层世界观：博主的市场模型

博主所有判断都建立在一个统一前提上：**相亲是「对对碰市场」，不是自由恋爱。** 语料中出现频次最高的机制词正是这套模型的自白：

| 机制词 | 出现条数 | 含义 |
|---|---|---|
| 梯度择偶 | 158 | 男可上迁、女多上嫁，条件按档位流动 |
| 价值互换 | 133 | 匹配的本质是价值对价，不是感觉 |
| 画像匹配 | 112 | 每个人可被归入一个「画像」档位 |
| 预期管理 | 62 | 机构的服务本质是校准客户预期 |
| 概率筛选 | 42 | 匹配是概率问题，不是努力问题 |
| 信息不对称 | 21 | 客户不知道自己真实市价 |

**87.5% 的样本视频**（175/200）都出现了「配得感 / 画像 / 预期管理」这类机制语言——也就是说，这套市场模型不是偶尔提及，而是博主话语的**骨架**。

### 1.1 四个核心公理

1. **对价公理**：`你的可选范围 = 你的价值档位`。价值不够，要求再合理也没用。
2. **稀缺公理**：优质标的供给极少且**极速流转**——「不是你不配，是根本见不到」。语料原话：「体制内小美极早被市场消化」。
3. **梯度公理**：女性上嫁、男性上迁均在可选范围内，但**须以自身档位为上限**。
4. **预期公理**：客户对自身档位的估计系统性偏高，需专业「校准」——这正是服务卖点本身。

## 二、维度与权重

按语料中「被博主点名点评的频次」与「被当作一票否决项的次数」排序。

### 2.1 男方维度（对其择偶竞争力的影响）

| 序 | 维度 | 权重 | 语料依据 |
|---|---|---|---|
| 1 | 房产 / 置业能力 | ★★★★★ | 「女孩普遍要求有房，没房难找」「不买房和娶老婆间选不买房，本质是不想结婚」 |
| 2 | 收入水平 | ★★★★★ | 「高收入加购房能力你这画像竞争不了」 |
| 3 | 职业性质（编制/体制内） | ★★★★ | 「无编制」被高频点名为短板 |
| 4 | 身高 | ★★★★ | 苏南市场身高普遍预期 ≥173；「身高1.88」这类要求被判过窄 |
| 5 | 年龄 | ★★★ | 男方年龄弹性大于女方，但 35+ 开始显著扣分 |
| 6 | 家庭资产 / 父母助力 | ★★★ | 「父母可出三四十万首付」被视为加分；A8/A9 分级话术 |
| 7 | 学历 | ★★ | 「大专学历」多次被点名为短板 |
| 8 | 户籍地域 | ★★ | 苏北籍在苏南找本地女「稍吃力」 |
| 9 | 外貌（小帅） | ★★ | 「颜值」在男方是加分项而非门槛 |
| 10 | 性格/情绪价值 | ★★ | 「松弛」「情绪价值」高频出现 |
| 11 | 婚史 | ★ | 离异在男方扣分弱于女方 |

### 2.2 女方维度

|---|---|---|---|

| 2 | 外貌 / 颜值 | ★★★★★ | 「小美」「长相小美」是高频标签；「吃到过颜值红利的只会让自己更难脱单」 |

| 5 | 职业性质（编制） | ★★★ | 「体制内小美」被视为顶配标签 |
| 6 | 家庭资产 / 父母助力 | ★★★ | 「父母一方体制内」「家里现金多」被当作硬加分 |
| 7 | 婚姻状态与子女 | ★★★ | 「39岁离异带娃别挑了能找到就不错了」 |
| 8 | 收入 | ★★ | 「女生收入自己花」被博主当作正常而非优势 |

## 三、硬门槛规则（If–Then）

标记 **[强]** 的规则在语料中被博主用作**一票否决**；**[软]** 为可协商但显著影响结论。

| # | 规则 | 强度 | 语料依据 |
|---|---|---|---|
| R01 | 若 男.无房 且 女.要求有房 → 判定为**基本淘汰** | **[强]** | 「无房基本被淘汰」 |
| R02 | 若 女.年龄≥33 且 要求 男.未婚+体制内 → 判定 **不现实/许愿** | **[强]** | 「37岁离异未育想找未婚体制内是许愿」 |
| R03 | 若 男.户籍=苏北 且 要求 女.苏南本地 → 匹配难度**上跳一档** | **[强]** | 「苏北人在苏南找本地姑娘稍吃力」 |
| R04 | 若 身高要求区间 ≤3cm → 有效池**骤减**，判定偏难 | **[软]** | 「身高卡太死（160-163）」 |
| R05 | 若 任一方 离异带孩 → 可匹配层级**下沉一档** | **[强]** | 「39岁离异带娃别挑了」 |
| R06 | 若 女.收入 > 男.收入 且 女方设「收入不低于我」门槛 → 有效池**腰斩** | **[软]** | 女主强案例普遍被要求降预期 |
| R07 | 若 男.身高<170 且 无编 且 农村低资产 → 判定「正常渠道基本找不到」 | **[强]** | 「矮个农村无编男正常渠道基本找不到对象」 |
| R08 | 若 女.年龄 23-28 且 外貌≥4分 且 学历≥本科 → 判为**顶配画像**，选择权在己 | **[软]** | 「漂亮学历好工作好的美女竞争力已极强」 |
| R09 | 若 子女性别结构不利（如女方有多个弟弟） → 记为**显著短板** | **[软]** | 「江西女有两个弟弟护士专升本短板真多」 |
| R10 | 若 男.资产档位 A_x 且 目标女方 A_{x+1} → 判定「有可能但须卡其他项放宽」 | **[软]** | 「自身A8颜值过6找A9有可能但卡工作」 |
| R11 | 若 一方父母/本人性格强势 → 匹配难度**结构上升**（与条件无关） | **[软]** | 「妈妈性格强势对儿媳不好相处」 |
| R12 | 若 职业=电商/自由职业/无业 且 圈子单一 → 判定「见不到优质标的」 | **[软]** | 「电商女应混电商圈接触一米八群体」 |
| R13 | 若 男.职业=体制内 且 年龄≥33 且 优越感强 → 从加分**反转为减分** | **[软]** | 「体制内大龄男优越感太强女生反馈全糟」 |
| R14 | 若 男.极抠门/消费计较 → 判定「图家庭不值」，建议分手 | **[软]** | 「男方极抠消费计较，图家庭不值」 |
| R15 | 若 女方要求「对方必须有房有车 + 体制内 + 本科」三项叠加 → 判定**要求过高不匹配自身** | **[强]** | 硬门槛统计中出现≥3项叠加的案例全部被判负 |

## 四、地域校准（苏锡常特化）

规则库落地时须做本地化，语料显示博主自己就在做这件事：

- **本地优先本地**：「苏南本地有排斥外地倾向，本地优先本地」。
- **地域层级**：上海 > 苏州/无锡市区 > 常州 > 苏北；跨层上迁难度按层级差递增。
- **资产分级话术**：A8（千万级）/A9（亿级）被当作口语化的财富分档，用于快速定位「画像」。
- **体制内密度高**：苏南体制内岗位密度高，导致「编制」成为准入门槛而非加分项。

## 五、博主的话术结构（任务一的核心证据）

从 200 条已蒸馏样本中还原出的**标准判断流程**：

```
① 问条件（年龄/身高/学历/收入/房车/家庭/户籍）
        ↓
② 归入「画像」档位（A8/A9、小美/普通、体制内/私企…）
        ↓
③ 比对要求与画像 → 指出「要求高于画像」
        ↓
④ 给出结论：追不到 / 偏难 / 需降低标准
        ↓
⑤ 抛出解决方案：择偶定位咨询（收费）
```

### 5.1 关键发现：博主自己回应了「压价」质疑

语料中存在**直接回应**该质疑的视频（账号B，96秒）：

> 顾客质疑：**「我们就是靠压低对方的配得感来制造交易来赚钱的」**
> 博主回应：不存在金钱利益关系，并解释——
> **「我给到的画像基本上都是在六十分左右的……因为很简单，不需要我给他们去抬高画像，人自己会往上走。我给到别人一个相对高的画像，只能让这个女生或者这个男生她的预期越来越高。因为人只会想要更好的人。」**

这段自述把机制说得很清楚：**主动把客户的可匹配档位往下压到 50-60 分区间，理由是防止客户预期上浮。** 博主同时在其他视频中明确否认自己在做「PUA / 两头打压」，主张「市场本就如此」。

### 5.2 量化证据（截至 200 条样本全量）

| 指标 | 男自述 | 女自述 |
|---|---|---|
| 案例数 | 64 | 98 |
| **贬低率**（追不到 / 偏难 / 需降低标准） | **51.6%** | **69.4%** |

- 总体：162 个有明确结论的案例中，**101 个（62.3%）为负面结论**，正面「可以」39 个（24.1%），最高频单一建议是「需降低标准」（44 次）。
- 性别差 **17.8 个百分点**（女 − 男）—— 这不是对称的「两头压价」，而是**女方端被否定得更重**。方向值得注意：博主对女性客户的期望打压力度显著更大。
- 条件弹性：低档 88.9% / 中档 68.4% / 高档 41.5%。**即便条件处于高档，仍有约四成被判负**，但整体随条件改善单调下降。

> ⚠️ 局限：本语料为**自然发生的真实咨询案例**，不含受控的「性别镜像对」。配对检验（998 组）双方同判负率 38.8%，未显著高于独立假设期望 35.8%，**该检验无效、应予弃用**；性别差异结论依据 `neg_rate_by_gender` 的直接统计。
> 另注：导流钩子与贬低率不相关（含钩子 63.6% vs 不含 61.9%），**「为导流而制造焦虑」的动机假设不成立**；但博主话语中内置的「压预期」方法论（画像只给 60 分）确实存在。

## 六、与「合拍率」H5 引擎的映射

| 规则库概念 | H5 引擎实现 |
|---|---|
| 价值档位 / 画像 | `competitiveness()` 输出 0-100 竞争力分（按性别中位基准锚定到 50 分） |
| 男女维度权重差异 | `WEIGHTS.M` / `WEIGHTS.F`，已按上表 ★ 数量级设定 |
| 硬门槛 | Q14 多选 → `gateFail()` 一票否决检测 |
| 可接受区间 | Q15 → `rangeDrift()` 偏离度计算 |
| 「你追不追得到」 | `oneWay()` 五档定位：优选 / 偏上 / 偏中 / 偏下 / 高攀 |
| 双向压价 | `matchBoth()` 同时输出两个方向 + 结构性诊断 |
| 降预期建议 | `relaxationAdvice()` 放宽哪项要求最划算 |

**产品取向建议**：由于规则库证实「双向都难」是**真实市场门槛 + 女方端更强的预期校准**共同造成的，H5 不应复制博主的否定式话术，而应把「双向偏中 = 门当户对」明确标为最优结果，并在双向都判难时提示「要求错位」而非「你不行」。这正是本产品的差异化定位。
