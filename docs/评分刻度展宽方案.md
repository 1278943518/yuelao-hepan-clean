# 评分刻度展宽方案（v5 候选）

> 目的：解决「条件差异明显的人，分数和匹配度却挤在一起、看不出差别」。
> 状态：**待 Leo 拍板**，未实施、未发布。
> 诊断脚本：`scripts/score_spread_probe.js`（只读，可复跑）；实测数据：`tmp/score_spread_probe.json`

## 一、根因：不是权重错，是**刻度没用满**

现有链路（`match/public/engine.js` → `match/server.js` → `match/public/app.js`）：

```
维度分(0-100) --权重加权--> raw  --S = 50 + (raw − 该性别基准)--> 竞争力分 S
                                        ↓
                              diff = S_我 − S_A  → 五档定位
                                        ↓
                        匹配度 = 100 − min(40, |diff|×1.6) − 门槛/区间/结构扣分
```

三个实测结论（合成人口重采样，N=20000/性别，配对 40000 组）：

| 指标 | 现状实测 | 说明 |
|---|---|---|
| 竞争力分 S 实际跨度 | P5 **38.9** → P95 **55.3**，min 24.7 / max 64.6，sd **4.97** | 标称 0-100，**实际只用了 25-65 这一段**，一半区间闲置 |
| levelOf 档位 | 「显著高于平均」(≥78) 与「中上」(≥62) 实测占比 **≈0%** | 天花板 64.6 < 62，**这两档根本不可达**，几乎人人「中等」 |
| 两人 \|分差\| | P50 **4.8**，**59.9%** 的配对 \|diff\| < 6，\`mid\` 档占 **60.2%** | 绝大多数组合落「门当户对」，档位没有分辨率 |
| 匹配度（仅分差项） | P10 **81** / P50 **92** / 均值 **90** | 任意两人都显示「非常匹配/比较匹配」 |
| 匹配度分档「差距偏大」(<40) | **0%（不可达）** | 分差项封顶 40 → 下限 60，该档只能靠门槛扣分触发 |

**一句话**：raw 是十几个维度的加权平均，个体差异被平均掉了（sd 只有 5 分）；而 S 又是 `50 + Δ` 的 1:1 映射、匹配度罚分斜率仅 1.6，于是整条链路上所有数字都被压在窄带里。

## 二、方案对比（均已在诊断脚本里跑出实测）

| | 方案 A：线性展宽 | **方案 B：Δ 拐点映射（推荐）** | 方案 C：人口分位锚点 |
|---|---|---|---|
| 公式 | `S = 50 + K×(raw − ref)` | `S = 50 + 拐点(Δ)`，`Δ = raw − ref` | S = 按合成人口分位分段线性插值 |
| 参数 | K=2.4 | 中段 `\|Δ\|≤8` 斜率 **2.4**；超出部分斜率 **1.4** | 锚点 P5/P20/P50/P80/P95 → 30/41/50/62/76 |
| S 跨度(P5-P95) | 40.9 | **36.1** | 46 |
| S 的 sd | 12.41 | **11.15** | 12.74 |
| \|分差\| P50 / P90 | 12.0 / 29.1 | 10.8 / 25.6 | 12.1 / 29.3 |
| REFERENCE 是否仍 = 50 | 是 | **是** | 否（变成 56.2 / 58.3，**要改现有测试断言**） |
| 改动量 | 一行 | 一个函数 + 一张常量表 | 一张 5×2 锚点表 + 改测试 |
| 风险 | 尾部把人推到 22 分（偏弱区），语义偏重 | 低：中段展宽、尾部压缩，不制造极端分 | 中：锚点值来自合成人口，需固化并注明口径 |

**推荐方案 B**。理由：展宽幅度与 A 相当，但不把尾部甩到极端分；同时保住 `REFERENCE = 50` 这个不变量，现有测试 `test_engine_match.js`（断言「男/女基准画像竞争力 === 50」）不用改。

> ⚠️ 口径声明：诊断用的是**合成人口**（按常识设定的边际分布），**不是真实用户数据**，对外不得引用。它的作用只有一个 —— 衡量「刻度利用率」和「展宽倍数」，**不用来定零点**。零点继续锚在 `REFERENCE`（标定中位画像）。

## 三、必须成套改的四处（缺一处就白改）

只改 S、不改阈值，等于把「挤成一坨」从分数搬到档位上。**以下四处必须同时改**。

### 1. 展示刻度：`match/public/engine.js` `competitiveness()`（现 141-151 行）

```js
/* Δ 空间拐点映射：中段放大 ×2.4，尾段压缩 ×1.4 —— 保证 REFERENCE 恒 = 50。
 * 目的：raw 的个体差异被加权平均稀释（sd≈5），此处把差异在展示层还原。
 * 参数改动只需动这三个数，改完必须重跑 scripts/score_spread_probe.js 校验跨度。 */
const KNEE = { mid: 2.4, at: 8, tail: 1.4 };
function displayScore(delta) {
  const a = Math.abs(delta);
  const off = a <= KNEE.at ? KNEE.mid * a
                           : KNEE.mid * KNEE.at + KNEE.tail * (a - KNEE.at);
  return Math.round((50 + (delta < 0 ? -off : off)) * 10) / 10;
}
function competitiveness(p) {
  const { raw, dims, weights } = rawScore(p);
  const s = Math.max(5, Math.min(99, displayScore(raw - refScore(p.gender))));
  /* 其余返回结构不变 */
}
```

### 2. 自身档位：`engine.js` `levelOf()`（现 153-159 行）

按**新刻度实测分位**选切点（规则：切点 = 新刻度的 P95 / P80 / P25 / P5）：

```js
function levelOf(s) {
  if (s >= 63) return { t: '显著高于平均', tone: 'good' };
  if (s >= 53) return { t: '中上', tone: 'good' };
  if (s >= 36) return { t: '中等', tone: 'ok' };
  if (s >= 27) return { t: '中下', tone: 'warn' };
  return { t: '偏弱', tone: 'risk' };
}
```

目标占比：显著 ≈5% / 中上 ≈15% / 中等 ≈55% / 中下 ≈20% / 偏弱 ≈5%。
（现状是「显著」与「中上」≈0%。**这四个切点必须由探针实测复核**，不要照抄。）
