# 相亲匹配判断规则库 v3.0

> 来源：抖音三个账号共 **300 条**视频口播转写稿的结构化蒸馏。
> - **账号A** 苏锡常大王说媒（100 条）
> - **账号B** 苏州金大王（100 条）
> - **账号C** 天书定位（100 条）｜抖音号 `45123772749`
>
> A 与 B 签名、微信号、办公地址一致，实为同一机构的两个分发账号；C 是**独立第三方**（择偶定位咨询 + 一对一牵线，签名挂 6 个微信号），这使 v3 第一次能做**跨博主对照**。
> 用途：① 还原博主判定「你追不追得到」的底层规则；② 作为「合拍率」评分引擎的规则来源。

## 版本说明：v2 → v3 做了什么

| 维度 | v2.0 | v3.0 |
|---|---|---|
| 样本 | 200 条（A+B） | **300 条**（A+B+C） |
| 案例 | 162 例 | **216 例** |
| 规则素材 | 452 条 | **757 条** |
| 观点主张 | — | **1614 条** |
| 内容类型 | 未细分来源 | **按博主分层**（发现 C 是「方法论型」而非「点评型」） |
| 跨博主对照 | 无 | **有**：三博主贬低率 57.3% / 67.5% / 51.9% |
| 标签质量 | — | 修正了 v2 遗留的 **B 账号被误标为 A** 的缺陷（100 条） |

**v3 最重要的一件事**：引入独立第三方博主 C 后，「双向压价是行业普遍话术」这一假设被**部分证伪**——三个博主贬低率差异达 **15.6 个百分点**（B 67.5% vs C 51.9%），说明「压价」不是一个统一的话术模板，而是**博主主体特征**（详见第 4.6 节）。

## 一、底层世界观：博主的市场模型

博主所有判断都建立在统一前提上：**相亲是「对对碰市场」，不是自由恋爱。** 语料中机制词的出现频次（300 条）：

| 机制词 | 出现条数 | 占比 | 含义 |
|---|---|---|---|
| 梯度择偶 | 196 | 65.3% | 男可上迁、女多上嫁，条件按档位流动 |
| 价值互换 | 196 | 65.3% | 匹配的本质是价值对价，不是感觉 |
| 画像匹配 | 167 | 55.7% | 每个人可被归入一个「画像」档位 |
| 预期管理 | 113 | 37.7% | 机构的服务本质是校准客户预期 |
| 概率筛选 | 77 | 25.7% | 匹配是概率问题，不是努力问题 |
| 信息不对称 | 59 | 19.7% | 客户不知道自己真实市价 |
| **压价** | 22 | 7.3% | 主动压低对方或自身的配得感 |
| 抬价 | 9 | 3.0% | 反向操作，抬高预期 |

**84.0% 的样本视频**（252/300）出现「配得感 / 画像 / 预期管理」这类机制语言——这套语言是博主话语的**共同骨架**，三个账号无一例外。

### 1.1 五条核心公理

1. **对价公理**：`你的可选范围 = 你的价值档位`。价值不够，要求再合理也没用。
2. **稀缺公理**：优质标的供给极少且**极速流转**——「不是你不配，是根本见不到」。
3. **梯度公理**：女性上嫁、男性上迁均在可选范围内，但**须以自身档位为上限**。
4. **预期公理**：客户对自身档位的估计系统性偏高，需专业「校准」——这正是服务卖点本身。
5. **解释成本公理**：**标签的解释成本本身就是定价项**。未婚生子、悬殊年龄差、背景存疑等，即使不影响硬条件，也会因「讲不清」而大幅折价——语料原话：**「未婚生子还不如二婚生育，解释成本太高了，你怎么跟人家说呀」**。

### 1.2 v3 新增：路径依赖公理（来自博主 C）

博主 C 提出与前四条不同性质的约束：**早期婚恋选择会持续收窄后续正常匹配空间**。

> 语料（26 岁男，19 岁起与 33 岁离异带娃姐姐相恋七年并育有一子）：
> 「你十九岁到二十六岁再干这个事，你后续正常婚恋不太容易找」
> 「就像我们现在正常婚恋男生比女生大六岁应该是很合理的对吧，但是往小时候放大六岁就相当于我上大一的时候谈了小学毕业的」

这条公理引入了**时间维度**——价值不是静态档位，而是会被历史选择改写。这是 A/B 语料里没有的视角。

## 三、跨博主对照（v3 核心增量）

### 3.1 三博主横向对比

| 博主 | 案例数 | 负面结论 | 正面结论 | **贬低率** | 主导内容类型 |
|---|---|---|---|---|---|
| A 苏锡常大王说媒 | 82 | 47 | 21 | **57.3%** | 案例点评 81% |
| B 苏州金大王 | 80 | 54 | 18 | **67.5%** | 案例点评 75% |
| C 天书定位 | 54 | 28 | 13 | **51.9%** | 案例点评 42% + 方法论 19% |

**极差 15.6 个百分点。** 若「压价」是统一的话术模板，三家应趋于一致；实测差异显著，说明贬低倾向是**博主个体属性**，而非行业共识。

### 3.2 内容策略差异

- **A/B 型（点评驱动）**：以「某人自述 + 博主判负」为主，案例占比 75–81%，靠具体案例制造冲突感。
- **C 型（方法论驱动）**：案例只占 42%，方法论占 19%，另外有 10 条「无口播内容」、8 条「现场花絮」、8 条「服务介绍」。
  C 的定位是「读懂因变量，看懂更多话术，少踩很多坑」——**他直接教观众识别话术，而不是单纯输出判断**（这条本身很讽刺：一个博主在教你怎么防博主）。

### 3.3 对 H1 假设的影响

原假设 H1「双向压价话术结构」需要**重新表述**：

| 子命题 | v3 结论 |
|---|---|
| H1a 对称性（男女同条件同结论） | **证据不足**（镜像对 1599 组，双负率 37.8% vs 独立期望 32.6%，差异不显著） |
| H1b 条件弹性（条件改善结论不翻转） | **反向证据**：高档贬低率 35.6% vs 低档 81.8%，**随条件改善显著下降** → 更像真实市场约束 |
| H1c 动机性（贬低服务于导流） | **弱证据**：含钩子贬低率 56.5% vs 无钩子 61.8%（有钩子的反而更低） |
| **H1d 主体性（v3 新增）** | **成立**：贬低倾向在博主间差异达 15.6pp，是主体特征而非行业模板 |

## 四、实证回测

### 4.1 性别差异

| 自述方 | 样本 | 贬低率 | 正面 | 中性 |
|---|---|---|---|---|
| 男 | 82 | **47.6%** | 27 | 16 |
| 女 | 130 | **68.5%** | 25 | 13 |
| 未知 | 4 | 25.0% | 0 | 1 |

**女性自述被贬低率高出 20.9 个百分点。** 但注意：这与「条件分布」高度混杂——女性自述案例本身可能条件更差（或博主认为女性更该被「校准预期」），不能直接读作性别歧视证据。

### 4.2 条件弹性（最关键的一项检验）

| 条件档次 | 样本 | 贬低率 |
|---|---|---|
| 低档 | 11 | **81.8%** |
| 中档 | 129 | 68.2% |
| 高档 | 59 | **35.6%** |

**贬低率随条件改善而单调下降**（81.8% → 68.2% → 35.6%）。这是**支持 H0（真实市场约束）**的最强证据：如果博主只是想压价，条件好坏不该影响结论；实际影响巨大，说明博主在按条件做区分。

> 但仍有解释空间：**高档条件被判「可以」不等于博主认同其要求**，可能只是「她条件好所以她说得对」。要彻底区分，需要看**高档女性的具体要求是否仍被驳**——建议后续做该子集的人工抽检。

### 4.3 结论方向分布

| 结论 | 条数 |
|---|---|
| 需降低标准 | 65 |
| 可以 | 52 |
| 偏难 | 42 |
| 看情况 | 30 |
| 追不到 | 22 |
| 未给出 | 5 |

**「可以」占 24.1%**——博主并非一味判负，约 1/4 的案例给出正面结论。这进一步削弱「无差别压价」的说法。

### 4.4 动机性检验

| 分组 | 样本 | 贬低率 |
|---|---|---|
| 含导流钩子 | 85 | 56.5% |
| 无导流钩子 | 131 | 61.8% |

**含钩子的贬低率反而更低**（-5.3pp）。若贬低是为导流服务，应观察到正相关——实测方向相反，H1c 不成立。

> 局限：钩子标注依赖 `hooks` 字段召回，可能低估（很多视频在评论区或主页挂微信，转写稿里看不到）。

### 4.5 高频短板与硬门槛

**被点名最多的短板（博主视角）**：
年龄偏大(9) | 长相普通(8) | 家庭无助力(5) | 无恋爱经验(5) | 性格强势(5) | 收入偏低(4) | 离异(4) | 大专学历(4)

**出现频率最高的硬门槛**：
本科(5) | 门当户对(5) | 本科以上(4) | 有房有车(4) | 身高178以上(3) | 父母一方体制内(3) | 本地人(3) | 体制内(3)

注意：**短板项里「年龄」出现 3 次以上不同表述（年龄偏大/30/34/29）**，合并后是绝对第一短板。门槛项里「本科」+「本科以上」合并 9 次，是第一硬门槛——比「有房有车」更高频。

### 4.6 v3 反直觉发现

1. **「压价」不是行业模板**：三博主贬低率极差 15.6pp（见 3.1）。
2. **条件越好越不被贬**：单调下降，与「无差别压价」相悖。
3. **导流钩子与贬低负相关**：削弱「贬低为卖货」的动机假说。
4. **C 在教观众防话术**：一个择偶定位博主，把「识别话术」做成了内容主线——说明这套话术结构在业内**已是公开知识**。
5. **学历门槛高于房产门槛**：与「男方经济决定论」的刻板印象不符（本科类要求 9 次 vs 有房有车 4 次）。

## 五、规则族库（757 条素材，按维度归族）

以下为规则素材的高置信度样例，完整索引见 `data/analysis/rules_index.json`。

### 5.1 择偶定位族

| WHEN | THEN | 依据 |
|---|---|---|
| 进入感情婚姻前 | 先做择偶定位 | 定位不清则所有匹配都是碰运气 |
| 客户择偶定位不清 | 先做定位咨询再相亲 | 避免无效消耗 |
| 婚内出问题想离婚 | 先咨询别急离 | 区分原则性与非原则性问题 |

### 5.2 价值互换族

| WHEN | THEN | 依据 |
|---|---|---|
| 遇到明显超出市场对价的大方行为 | 警惕对方财富来源的合法性与可持续性 | 只有灰产与贪官才会非理性大方 |
| 评估一个人的消费与付出习惯 | 看其对自己财富可持续性的判断（还能花多久） | 花钱习惯与财富安全感相关，而非与总量 |
| 判断自己是否真的在付出 | 只计算纯粹送给对方的钱与物，剔除共同消费 | 共同消费不是付出 |

### 5.3 颜值门槛族

| WHEN | THEN | 依据 |
|---|---|---|
| 客户硬条件强但颜值要求占比过高 | 指出卡颜值本身成立，但会显著收窄可选池，须配合向下匹配 | 颜值是稀缺资源 |
| 当事人坚持卡颜值 | 在颜值之外的所有方向都必须让步 | 要求不能只上不下 |
| 当事人愿意舍掉颜值要求 | 择偶难度立刻大幅下降，很好匹配 | 颜值是最贵的单一维度 |
| 女生身高174且自认是缺点 | 先看体重，身材好则是加分，身材差才是扣分 | 身高需与身材联合定价 |

### 5.4 性格匹配族（v3 强化）

| WHEN | THEN | 依据 |
|---|---|---|
| 女方性格强势 | 匹配对象应为相对内向、正统、愿意承接其主导权的人 | 主导权需单边让渡 |
| 客户对伴侣的唯一不满是「不够有趣」 | 判定为极轻微缺点，不构成换人理由 | 性格短板不等于硬伤 |
| 客户条件优秀但过往恋爱总被分手 | 归因于性格而非条件 | 条件好还留不住，问题在性格 |

### 5.5 婚史与解释成本族

| WHEN | THEN | 依据 |
|---|---|---|
| 评估未婚生子的折价 | 解释成本高于二婚生育 | 「怎么跟人家说」是真实成本 |
| 评估出轨的伤害量级 | 按性别差异折算，而非按「出轨」二字直接定罪 | 语境决定量级 |
| 对方养家但出轨，当事人纠结是否继续 | 看工作、孩子年龄、对方回归家庭的可能性再定 | 决策看综合效用 |

### 5.6 关系修复族

| WHEN | THEN | 依据 |
|---|---|---|
| 伴侣因家人重病而牺牲事业与经济收入 | 判定为合理选择，应无条件支持 | 重大变故下无绝对对错 |
| 夫妻因重大外部变故产生分歧 | 先定性是否原则性问题 | 非原则性问题应互相理解 |
| 关系出现阶段性危机（如三十多岁七年之痒） | 拉长周期看，四十多岁后常自然回归 | 危机有阶段性 |

## 七、方法与局限

### 7.1 方法

1. **采集**：TikHub API 拉取三博主各 100 条作品元数据
2. **转写**：faster-whisper（base 模型），并发 4，约 5.5–7× 实时
3. **蒸馏**：按 `docs/distill_spec.md` v2 schema 逐条结构化，抽取案例字段 + 观点主张 + if-then 规则
4. **聚合**：`scripts/aggregate.py` 做性别差异、条件弹性、镜像对、动机性四类检验
5. **索引**：`scripts/index_rules.py` 按维度归族

### 7.2 局限（必须承认）

1. **转写噪声**：bloggerC 方言口音重，同音字错误多，部分条目 `confidence` 标 `mid`；数字类信息以语义推断为主。
2. **钩子召回不足**：`hooks` 字段只能从口播稿提取，主页/评论区挂的联系方式看不到，导致 4.4 的动机性检验可能低估。
3. **镜像对构造粗糙**：目前按「条件档次 + 门槛强度」配对，未做逐维度精确匹配，1599 组里可能有噪声。
4. **样本选择偏差**：只取每博主最近 100 条，不代表其全部内容，也不代表整个行业。
5. **「贬低」的判定标准**：依赖 verdict 归一化字面匹配，未做双人编码与 Kappa 一致性检验（原方案要求但未执行）。
6. **因果不能反推**：条件弹性成立 ≠ 博主完全客观，只说明其判断与条件相关。

### 7.3 后续建议

- [ ] 对「条件高档但要求高」的子集做人工抽检，看是否仍被驳（检验 4.2 的替代解释）
- [ ] 补做双人编码 + Kappa 一致性（这是原方案的硬要求）
- [ ] 若能拿到博主 C 的联系方式渠道（6 个微信号），可观察其是否用「先贬后卖」的转化路径

## 八、与「合拍率」引擎的映射
